# SPM: Syeikh Prompt Master

Syeikh Prompt Master (SPM) adalah satu aplikasi web modular yang direka untuk membantu pengguna menjana prompt AI yang berkualiti tinggi, profesional, dan berstruktur.

## Ciri-ciri Utama
- **Modular Design**: HTML, CSS, dan JS yang berasingan untuk penyelenggaraan mudah.
- **Expert Templates**: Menggunakan kerangka kerja "Expert Mode" untuk hasil AI yang lebih baik.
- **Professional UI**: Rekaan minimalis yang memfokuskan kepada produktiviti.
- **Copy-to-Clipboard**: Memudahkan pemindahan prompt ke ChatGPT/Claude/Gemini.

## Pembangunan
