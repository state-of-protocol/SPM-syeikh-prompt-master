**Syeikh Prompt Master (SPM) v3.0** adalah sistem dwi-platform (Web + CLI) yang dioptimumkan untuk kelajuan, kecekapan, dan monetisasi.

## 🚀 Core Features
- **Integrated Dashboard**: Real-time USD valuation and daily goal progress tracking.
- **Micro-interactions**: Apple-grade smooth animations and zero-latency inputs.
- **Wealth Sentinel**: Python CLI for autonomous market strategy and product synthesis.
- **PC Surgeon**: Advanced Windows diagnostic and optimization suite for high-value services.
- **Auto-Persistence**: Zero-loss local storage for strategic sessions.

## 📂 Project Structure
- `index.html`: Unified lean UI.
- `style.css`: High-performance Apple styling.
- `script.js`: Integrated logic engine.
- `wealth_engine.py`: The market sentinel.
- `spm_surgeon.py`: The industrial PC service.

## 🛠️ Usage
1. Open `index.html` for strategic prompt generation.
2. Run `python wealth_engine.py` for autonomous wealth commands.
3. Run `MULA_SERVIS.bat` for professional PC maintenance.
