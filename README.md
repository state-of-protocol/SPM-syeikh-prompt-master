**Syeikh Prompt Master (SPM)** bukan sekadar pembina prompt biasa. Ia adalah sebuah ekosistem dwi-platform (Web UI + Python CLI) yang direka secara strategik untuk satu matlamat tunggal: **Menjana $250 USD sehari melalui produk digital dan SaaS.**

---

## 🚀 Komponen Utama Sistem

### 1. **Web UI: Apple-Minimalist Workstation**
Antaramuka web yang direka dengan *Apple Design Language* untuk pengalaman pengguna yang mahal, kemas, dan pantas.
- **Deep Profiling**: Integrasi Nama, DOB, dan Cita-cita untuk personalisasi output AI.
- **Industry Tick Mode**: Pilihan modular bagi kluster industri berimpak tinggi (FinTech, AI, GreenTech, dsb).
- **Valuation Engine**: Pengiraan nilai pasaran prompt dalam **USD** secara real-time.
- **Live Preview**: Penjanaan prompt automatik (Zero-Latency) semasa anda menaip.
- **Auto-Persistence**: Sistem *Auto-Save* (Local Storage) untuk mengelakkan kehilangan data.

### 2. **Python CLI: The Wealth Sentinel** (`wealth_engine.py`)
"Senjata" rahsia yang dijalankan terus melalui PowerShell untuk operasi autonomi.
- **Economic Sentinel**: Sentiasa berorientasikan target $250/hari.
- **Market Arbitrage Logic**: Mencari peluang pasaran dan blueprint produk digital secara automatik.
- **Autonomous Reasoning**: Menggunakan *Master Prompt Injection* untuk memastikan AI tidak lari dari matlamat kewangan.

## 🛠️ Pemasangan & Penggunaan

### A. Menjalankan Web UI
Hanya buka fail `index.html` dalam mana-mana pelayar moden. Tiada pemasangan diperlukan.
- **Rekomendasi**: Gunakan Safari atau Chrome untuk kesan *Glassmorphism* yang terbaik.

### B. Menjalankan Wealth Sentinel (CLI)
1. Pastikan anda mempunyai Python 3.9+.
2. Pasang library Gemini:
   ```bash
   pip install -q -U google-generativeai
   ```
3. Set API Key anda:
   ```powershell
   $env:GOOGLE_API_KEY="KOD_API_ANDA"
   ```
4. Jalankan Sentinel:
   ```bash
   python wealth_engine.py
   ```
